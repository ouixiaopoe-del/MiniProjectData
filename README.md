# Interactive Agricultural Price & Trend Dashboard
**Interactive Agricultural Price & Trend Dashboard** เป็นเว็บแอปพลิเคชันเชิงโต้ตอบที่พัฒนาขึ้นเพื่อนำเสนอและวิเคราะห์ข้อมูลราคาและปริมาณผลผลิตสินค้าเกษตร โครงการนี้เป็นส่วนหนึ่งของวิชา Data Visualization Technology (ระดับปริญญาตรี) โดยใช้ระยะเวลาในการดำเนินงานระยะสั้น 3 สัปดาห์

## 👥 สมาชิกกลุ่มและบทบาทหน้าที่

* **นาย ธรรมรักษ์ ธูปบูชา (66541207064-1):** รับผิดชอบการทำ Data Cleaning (จัดการ Missing Values, Outliers, Duplicates), การวิเคราะห์ข้อมูลเชิงพรรณนา (Descriptive Statistics) และสร้างโมเดลทดสอบ (Linear Regression / Trend Analysis)

* **นาย ปรกรณ์เกียรติ์ บริสุทธิ (66541207070-8):** รับผิดชอบการคัดเลือกชุดข้อมูล, จัดการ Repository บน GitHub, และทำหน้าที่เป็น Front-end Developer & UI/UX Lead ในการพัฒนา Web Application ด้วย D3.js และ Chart.js รวมถึงการ Deploy ผลงานขึ้นสู่ระบบสาธารณะ


## 🎯 วัตถุประสงค์และคำถามวิจัย (Business Understanding)

* **วัตถุประสงค์:** เพื่อวิเคราะห์ราคาและปริมาณผลผลิตสินค้าเกษตร เพื่อช่วยให้เกษตรกรหรือผู้บริโภคเห็นแนวโน้มตลาด
* **คำถามวิจัย:** "แนวโน้มราคาและปริมาณผลผลิตสินค้าเกษตรในแต่ละภูมิภาคมีความสัมพันธ์กันอย่างไร และสามารถนำเสนอผ่านเว็บแดชบอร์ดเชิงโต้ตอบได้อย่างไร?"
* **กลุ่มเป้าหมาย:** ประชาชนทั่วไป, นักวิเคราะห์ข้อมูลการเกษตร, และผู้สนใจศึกษาเปรียบเทียบเทคโนโลยีเว็บวิชวลไลเซชัน


## 🛠 เทคโนโลยีที่ใช้งาน (Tech Stack)

* **Front-end & UI:** HTML, CSS, JavaScript (ธีมสีเข้มสไตล์ Modern Dashboard)
* **Data Visualization:** D3.js (กราฟแท่งแนวนอน, Scatter Plot) และ Chart.js (กราฟโดนัท, พาย, กราฟเส้นแนวโน้ม)
* **Data Ingestion:** PapaParse (สำหรับไฟล์ CSV) และ SheetJS (สำหรับไฟล์ Excel)
* **Deployment:** GitHub Pages

## 📊 กระบวนการทำงานตามกรอบ CRISP-DM

### 1. การทำความเข้าใจข้อมูล (Data Understanding)

* ใช้ชุดข้อมูลเปิด (OpenData) `Agricultural_Price_Dataset_5550_Rows.xlsx`
* ตรวจพบว่าชุดข้อมูลเริ่มต้นมีจำนวน 5,550 แถว 11 คอลัมน์
* พบปัญหาข้อมูลซ้ำซ้อน 250 แถว, ข้อมูลราคาผิดปกติ (99999), และชื่อสินค้า/จังหวัดที่พิมพ์ไม่เป็นมาตรฐาน


### 2. การเตรียมข้อมูล (Data Preparation)

* **Duplicates:** ลบแถวที่ซ้ำกันทั้ง 250 แถวออก
* **Outliers:** แปลงค่าราคาที่เป็น 99999 ให้เป็นค่าว่าง (NaN)
* **Missing Values Imputation:** เติมค่าที่ขาดหายด้วยค่ามัธยฐานแยกตามกลุ่มสินค้า (Group Median Imputation by Product_Name)
* **Standardization:** ปรับแก้คำผิดและแปลงข้อมูลให้เป็นมาตรฐานสากลภาษาอังกฤษ เช่น เปลี่ยน "ข้าวหอมมารี" เป็น "Jasmine Rice", "โคราช" เป็น "Nakhon Ratchasima", และ "กิโลกรัม" เป็น "kg"


### 3. การวิเคราะห์ข้อมูล (Modeling & Analysis)

* **การทดสอบโมเดล:** ดำเนินการทดสอบ Linear Regression เพื่อพยากรณ์ราคา แต่พบว่ามีค่า Error (RMSE) สูง เนื่องจากความผันผวนตามฤดูกาล
* **วิธีที่เลือกใช้:** เปลี่ยนมาใช้ Descriptive Statistics & Trend Analysis ซึ่งสะท้อนพฤติกรรมตลาดจริงได้ดีกว่า และเหมาะสมกับการสร้างกราฟเชิงโต้ตอบ



### 4. การพัฒนาเว็บและการเผยแพร่ (Web Visualization & Deployment)

* **UI/UX Layout:** แบ่งหน้าจอเป็นแท็บชัดเจน ได้แก่ แท็บ Overview (KPI, Time-Series, กริดกราฟ 6 ช่อง) และ แท็บ Comparison & Raw Data (ตารางเปรียบเทียบ D3.js กับ Chart.js และตารางข้อมูลดิบ)
* **Interactivity:** มีระบบตัวกรองข้อมูล (Dropdown Filter) และ Tooltip เมื่อเลื่อนเมาส์ชี้
* **Drill-down Feature:** สามารถคลิกที่ตัวกราฟเพื่อเรียกหน้าต่างป๊อปอัป (Modal) แสดงรายละเอียดเชิงลึกของสินค้านั้นๆ ได้
* **Deployment:** เผยแพร่ผลงานผ่าน GitHub Pages ทำให้สามารถเข้าใช้งานได้ทันทีโดยไม่ต้องล็อกอิน
